# 三有 · 初禅之后

一款基于说一切有部阿毗达磨、受《俱舍论》启发的中文回合策略叙事游戏。

你可以追求更安稳的生活、更深的寂静。后来，你还要面对想留住它们的心。

## 直接游玩

下载仓库，双击根目录的 **`index.html`** 或 **`sanyou-offline.html`** 即可游玩，无需安装依赖、联网或配置 API Key。

源码与离线版均已就绪；当前仓库为私有，尚未启用公开的 GitHub Pages。

## 怎么玩

- 选择行脚者、在家人或问学者作为起点；三者的初始资源不同。
- 一局十八旬，每旬两次行动，预计约 10–15 分钟。
- 安排劳作、歇息、守护行持、济人、听闻思择、修止与观照，兼顾资粮与疲劳。
- 四项玩法条件达到后，留出两次行动，可进入本章的初静虑演示。
- 入定时查看五支，出定后面对如何回应过去安乐的分岔。
- 八个生活境遇与定后事件会影响后续选择；一局有八种可能的收束。
- 顶部可查看三界九地图与闻思录，右上菜单可下载离线版或保存行旅札记。
- 支持自动续玩、最近八步的撤回，以及可选环境音。声音默认关闭。

没有入定也可以完成一局。章节结局不按总分排名。

## 理论背景与玩法范围

以玄奘译《阿毘达磨俱舍论》所述有部／毗婆沙师义为背景。论中另有经部意见及论主评议，不能将全书每一种主张都等同有部定论。

| 本章表现的关系 | 基本出处 |
| --- | --- |
| 定静虑与生静虑有别，角色所生始终为欲界人趣 | 卷八《分别世品》、卷二十八《分别定品》 |
| 净初静虑立寻、伺、喜、乐、等持五支；乐支为轻安 | 卷二十八《分别定品》 |
| 净等至与出定后可能生起的味著分别呈现 | 卷二十八《分别定品》 |
| 得定与圣道断惑须分别观察 | 卷十九《分别随眠品》、卷二十三《分别贤圣品》 |

人物、故事、资源、效果、回合长度和入定门槛均为玩法创作；数值不是论典的修证量化条件。“慧解”不等于无漏慧或圣果，“牵著”不等于随眠总量。本章不模拟见道、完整心所相应、实际业果及全部断惑次第，不以分数兑换圣果。

本章可操作至初静虑，其余九地开放阅读。完整的三界九地交互项目见：

https://wanglu2016.github.io/jushe-sanjie-jiudi/

原典：[CBETA《阿毘达磨俱舍论》T1558](https://cbetaonline.dila.edu.tw/zh/T1558)。

## 运行、修改与验证

直接打开 `index.html`，或在仓库目录运行：

```bash
python3 -m http.server 8000
```

然后打开 `http://localhost:8000/`。

修改 `src/` 下的文件后，重新生成两个单文件版本：

```bash
python3 build.py
```

验证游戏规则（需要 Node.js）：

```bash
node verify.cjs
```

检查覆盖入定条件、净定后的不同分岔、可复现的存档、2,001 局完整回合及八种结局的可达性。

## 目录

```text
index.html             可直接打开的游戏入口
sanyou-offline.html    单文件离线版
build.py               重新生成 HTML
verify.cjs             游戏规则验证
src/
  shell.html           页面结构
  style.css            样式与响应式布局
  engine.js            状态、行动、事件与结局
  art.js               程序绘制的矢量山林场景
  app.js               页面交互、存档与导出
```

全部样式与脚本内嵌，无外部脚本、字体或 AI 服务依赖。进度保存在当前浏览器；清除浏览器数据会失去进度，不同网站地址与离线文件的进度独立。
